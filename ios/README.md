# NMail for iPhone

`NMailPhone` is the SwiftUI iPhone app on top of the same `MailCore` package the Mac app uses (Gmail client,
sync, GRDB store, MIME, compose, signatures, accounts). `project.yml` is the source of truth: `NMail.xcodeproj`
and `NMailPhone/Info.plist` are generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) and git-ignored.

```sh
brew install xcodegen   # once
cd ios && xcodegen generate && open NMail.xcodeproj
```

## Demo mode and screenshots

`MAIL_DEMO=1` runs on MailCore's fixtures with no network. `MAIL_SCREEN` picks a preset: `inbox`, `thread`, `html`,
`compose`, `search` (`MAIL_QUERY`), `mailboxes`, `accounts`, `settings`, `signin`, `swipe`, `empty`.
`MAIL_THEME=light|dark` forces a theme.

```sh
ios/scripts/snap.sh build/snaps              # every preset, light and dark
ios/scripts/snap.sh build/snaps thread       # one preset
```

The script boots a simulator with `simctl` and never opens Simulator.app.

## Google sign-in: the iOS OAuth client

The Mac app uses the Desktop client in `~/.config/mail/client_secret.json` (loopback redirect). iOS can't, so the
phone uses an **iOS** OAuth client: no secret, and Google redirects to the reversed client ID as a URL scheme.
`project.yml` holds a placeholder until you create it:

1. Open [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials) for project
   **longevity-leon**.
2. **Create credentials → OAuth client ID → iOS.** Bundle ID `com.timcvetko.nmail`, team ID `5Z5VDUY233`.
3. Copy the client ID, e.g. `1234567890-abcdefg.apps.googleusercontent.com`.
4. In `ios/project.yml`, set `GOOGLE_CLIENT_ID_PREFIX` to the part before `.apps.googleusercontent.com`:

   ```yaml
   GOOGLE_CLIENT_ID_PREFIX: 1234567890-abcdefg
   ```

   That sets both the `NMailGoogleClientID` Info.plist key (`1234567890-abcdefg.apps.googleusercontent.com`) and the
   URL scheme Google redirects to (`com.googleusercontent.apps.1234567890-abcdefg`). Run `xcodegen generate` again.
5. The consent screen is the one the Mac app already uses (same scopes). While it is in **Testing**, add every Gmail
   address you'll sign in with under **OAuth consent screen → Audience → Test users**, or publish the app. Test-mode
   refresh tokens expire after 7 days, so publishing avoids signing in again every week.

Until step 4 is done, "Sign in with Google" shows "This build has no Google client ID".

## TestFlight

One-time:

1. **Xcode → Settings → Accounts:** sign in with the Apple ID that belongs to team `5Z5VDUY233`.
2. **[App Store Connect](https://appstoreconnect.apple.com/apps) → Apps → + → New App:** platform iOS, name
   "NMail" (or any free name), bundle ID `com.timcvetko.nmail` (register it under Certificates, IDs & Profiles →
   Identifiers first if it isn't listed), SKU e.g. `nmail-ios`.
3. Create the iOS OAuth client and put its ID in `project.yml` (above). The upload script refuses to run with the
   placeholder.
4. Add yourself as an internal tester in App Store Connect → TestFlight.

Each release:

```sh
ios/scripts/testflight.sh
```

It runs `xcodegen generate`, archives for `generic/platform=iOS` with `-allowProvisioningUpdates` (automatic
signing creates the certificate and profile on first run), sets the build number to the git commit count, and
exports with `scripts/ExportOptions.plist` (`app-store-connect`, destination `upload`), which uploads the build.
It appears in TestFlight after App Store Connect finishes processing.

## What syncs when

Foreground only: on launch, when the app returns to the foreground, every 30 s while it is open, and on pull to
refresh. Background refresh (`BGAppRefreshTask`) is future work.
